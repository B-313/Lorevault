Using Lorevault

Quick-start guide

Save Lorevault to your desktop, open it in your browser and start recording. No installation, account or AI service is required. Choose a backup location to protect your entries.

Where your entries are saved

When you select Save record or Save weekly reflection, Lorevault stores the entry in the browser storage on this device. It does not create a document on your desktop or send entries to the internet. For a separate file you can keep or move, go to My logbook → Save a copy. Draft text that has not been saved may be lost if you close the page.

01

Save to your desktop and open

Download the Lorevault HTML file and move it to your Desktop. Double-click the file to open it in Chrome, Edge, Firefox or Safari. It runs locally in your browser, without installation, internet access or AI. You may also use the published website when you have internet access. Use the same file location and browser to return to your local entries, and keep backups because local-file storage can vary by browser.

02

Return to your logbook

For the desktop version, open the same HTML file in the same browser each time. For the online version, bookmark the published website and use the same browser and device. The desktop file and online website do not share saved entries. Use My logbook → Save a copy and Open a saved copy to transfer them.

03

Set up your placement

Under Daily records, select Add placement employer and duration. Enter the employer, location and placement start and end dates, then save. Lorevault calculates placement weeks and displays internship-day progress above the form. Select Edit placement details to change them later.

04

Add a daily record

Choose the date and day type, including Half-day or Public holiday. Enter working times where applicable. Add each task as a separate bullet using + Add another activity, then complete tools and technologies and the mandatory Planned follow-up activities field. Enter None if no follow-up is required.

05

Check and save

Select Check entry to run the privacy screening. Review the result, remove sensitive details where necessary, tick the confidentiality confirmation and select Save record. If you change the entry after checking it, run the check again. Screening is a safeguard, not a guarantee of legal or employer-policy compliance.

06

Review, edit or delete

Open Record archive to see saved daily records. Select an activity to view its details, Edit to update it, or Delete to remove it after confirmation. When updating an entry, check it again before selecting Update record. Deletion cannot be undone unless you restore an earlier backup.

07

Complete weekly reflections

Open Weekly reflections, choose the week starting date and complete the reflection fields for competencies, challenges, learning, outstanding issues, supervisory feedback and next-week priorities. Select Save weekly reflection. Saved reflections appear below the form.

08

Save a backup and restore it

After you select Save, records are stored automatically in this browser on your current device. To protect your work, select Choose backup location in My logbook. On supported desktop browsers you can choose a file location and Lorevault updates that file when you save. On other browsers, choose Save a copy and save the downloaded backup in a folder you can find again. Keep the downloaded .json file somewhere safe. To recover or transfer records, select Open a saved copy, choose that file, review the summary and confirm restoration. Restoring replaces the current logbook, so back it up first.

09

Generate your growth report

Save weekly reflections, then open Growth report and select Generate growth report. The report uses only competencies applied or developed and critical reflection and learning outcomes. In the print window choose Save as PDF. If the browser blocks the report window, allow pop-ups for Lorevault and try again. Review the report before sharing it.

Important to know

Browser storage is not a file in your Downloads or Desktop folder. It is separate for different browsers, devices and website addresses, and may be lost if browser data is cleared. Local HTML file storage can also vary by browser. Keep regular backups and avoid recording confidential employer information or personal data.
